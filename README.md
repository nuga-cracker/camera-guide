# Camera Guide Exhibit

필름카메라와 디지털카메라의 **구조, 기능, 촬영 모드, 작동 원리**를 초보자도 쉽게 이해할 수 있도록 만든 **인터랙티브 전시형 웹페이지**입니다. 큰 SVG 비주얼, 핫스팟 구조도, 모드 다이얼, 빛 경로 애니메이션, 노출 3요소 체험을 한 페이지에 담았습니다.

## 주요 기능

- **히어로 섹션**: 큰 카메라 SVG 일러스트와 시작 버튼 제공
- **인터랙티브 구조도**: 렌즈, 조리개, 셔터, 필름실/센서, 뷰파인더, 모드 다이얼, 셔터 버튼, 플래시를 클릭하면 쉬운 설명 표시
- **필름 ↔ 디지털 전환**: 카메라 종류를 바꾸면 강조되는 부품과 설명 카드 변경
- **촬영 모드 다이얼**: Auto, P, A/Av, S/Tv, M, Scene, Portrait, Landscape, Sports, Night, Macro, Movie, Bulb 설명 제공
- **작동 원리 애니메이션**: 빛이 렌즈를 지나 필름/센서에 기록되는 과정을 단계별로 시각화
- **노출 3요소 체험**: 조리개, 셔터 속도, ISO를 조절하며 배경 흐림, 움직임, 노이즈 변화를 미리보기로 확인
- **상황별 추천 모드**: 인물, 풍경, 스포츠, 야경, 음식, 접사, 동영상에 맞는 추천 모드 안내
- **접근성/반응형**: 키보드 포커스, aria-label, 명확한 대비, 모바일 대응 레이아웃 포함

## 파일 구성

- `index.html` — 페이지 구조
- `css/style.css` — 스타일, 반응형, 애니메이션
- `js/data.js` — 카메라 부품/모드/상황 데이터
- `js/main.js` — 인터랙션 로직
- `assets/camera-mark.svg` — 페이지에서 사용하는 SVG 아이콘

## 로컬 실행 방법

설치 과정이 필요 없는 정적 웹페이지입니다.

1. 저장소를 내려받거나 압축을 풉니다.
2. 저장소 루트의 `index.html` 파일을 브라우저에서 바로 엽니다.
3. 또는 간단한 로컬 서버가 필요하면 저장소 루트에서 아래 명령을 실행하세요.

```bash
python3 -m http.server 8000
```

그 다음 브라우저에서 `http://localhost:8000` 으로 접속하면 됩니다.

## GitHub Pages 배포 방법

1. GitHub 저장소에서 **Settings → Pages** 로 이동합니다.
2. **Build and deployment** 항목에서 **Deploy from a branch** 를 선택합니다.
3. Branch를 `main`(또는 배포할 브랜치), 폴더를 `/ (root)` 로 선택하고 저장합니다.
4. 잠시 후 표시되는 Pages URL로 접속하면 배포된 페이지를 확인할 수 있습니다.

## 구현 메모

- 외부 이미지 대신 **SVG 기반 비주얼**을 사용했습니다.
- 별도 빌드 도구 없이 **HTML + CSS + JavaScript**만으로 동작합니다.
- 설명 데이터는 `js/data.js`에 분리해 유지보수하기 쉽게 구성했습니다.
